# Robot Romance: One-Line Pickup Lines for AI

A dependency-free Python program that writes one original robot pickup line to
`entry.txt` in `MAKEFUN_OUTPUT_DIR` (default: `/output`). The UTF-8 output has no
trailing newline. The program reads the output back, checks the single-line and
character requirements, and prints its character count.

## Run it

```sh
python3 main.py
```

For a different output directory:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/robot-romance-test-out python3 main.py
```

The program creates the output directory if necessary and overwrites only
`entry.txt` on subsequent runs. No network, dependencies, secrets, or git history
are needed at runtime. `TOURNAMENT.md` records the original candidate comparisons;
these are editorial judgments, not published competition scores.
